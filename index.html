Projects

Bloodstain Pattern Analysis

A convolutional neural network that classifies bloodstain images as blunt-force impact or gunshot, to help forensic investigators reconstruct crime scenes with less human bias. Built with TensorFlow/Keras on 94 images (49 blunt, 45 gunshot), resized to 120×120 and augmented with rotation, shifting, zoom, and brightness changes. Class weighting, dropout, batch normalization, L2 regularization, and early stopping kept the small dataset from overfitting. Result: 80% accuracy on the held-out test set.

Next: expand the dataset, since more images are the clearest path to higher accuracy.
